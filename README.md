# YouTube Downloader

Веб-приложение для скачивания видео с YouTube в выбранном качестве.

## Возможности

- 1 Загрузка информации о видео по ссылке
- 2 Выбор качества видео
- 3 Скачивание видео в нужном формате
- 4 Список скачанных видео
- 5 Красивый веб-интерфейс
- 6 Поддержка разных расширений (MP4, WebM и т.д.)

## Требования

- Python 3.8+
- pip (менеджер пакетов Python)

## Установка и запуск

### 1. Создайте виртуальное окружение (рекомендуется)

```bash
# На Windows
python -m venv venv
venv\Scripts\activate

# На macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустите приложение

```bash
python app.py
```

Приложение будет доступно по адресу: **http://localhost:5000**

## Использование

1. Откройте браузер и перейдите на `http://localhost:5000`
2. Введите ссылку на видео YouTube в поле "Введите ссылку на видео"
3. Нажмите кнопку "Загрузить информацию"
4. Выберите нужное качество видео из предложенных вариантов
5. Нажмите кнопку "Скачать видео"
6. Видео будет сохранено в папку `downloads`

## Стек

- **Backend**: Flask (Python)
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Загрузчик видео**: yt-dlp
- **Сервер**: Flask Development Server


## Содержимое requirements.txt

- **Flask**: Веб-фреймворк для Python
- **yt-dlp**: Загрузчик видео с YouTube
- **python-dotenv**: Загрузка переменных окружения из .env файла
