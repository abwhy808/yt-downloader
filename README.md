# YouTube Downloader

Веб-приложение для скачивания видео с YouTube в выбранном качестве.

## 🌟 Возможности

- ✅ Загрузка информации о видео по ссылке
- ✅ Выбор качества видео
- ✅ Скачивание видео в нужном формате
- ✅ Список скачанных видео
- ✅ Красивый веб-интерфейс
- ✅ Поддержка разных расширений (MP4, WebM и т.д.)

## 📋 Требования

- Python 3.8+
- pip (менеджер пакетов Python)

## 🚀 Установка и запуск

### 1. Создайте виртуальное окружение (рекомендуется)

```bash
# На Windows
python -m venv venv
venv\Scripts\activate

# На macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустите приложение

```bash
python app.py
```

Приложение будет доступно по адресу: **http://localhost:5000**

## 📝 Использование

1. Откройте браузер и перейдите на `http://localhost:5000`
2. Введите ссылку на видео YouTube в поле "Введите ссылку на видео"
3. Нажмите кнопку "Загрузить информацию"
4. Выберите нужное качество видео из предложенных вариантов
5. Нажмите кнопку "Скачать видео"
6. Видео будет сохранено в папку `downloads`

## 🛠️ Доступные API Endpoints

### GET `/`
Возвращает главную страницу приложения

### POST `/api/get-formats`
Получить информацию о видео и доступные форматы

**Запрос:**
```json
{
  "url": "https://www.youtube.com/watch?v=..."
}
```

**Ответ:**
```json
{
  "title": "Название видео",
  "thumbnail": "https://...",
  "duration": 360,
  "formats": [
    {
      "format_id": "22",
      "quality": "720p",
      "ext": "mp4",
      "filesize": 52428800
    }
  ]
}
```

### POST `/api/download`
Скачать видео в выбранном формате

**Запрос:**
```json
{
  "url": "https://www.youtube.com/watch?v=...",
  "format_id": "22"
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Видео успешно скачано: Название видео"
}
```

### GET `/api/downloads`
Получить список всех скачанных видео

**Ответ:**
```json
[
  {
    "name": "Video Title.mp4",
    "size": 52428800,
    "modified": "2024-04-26T12:00:00"
  }
]
```

## ⚠️ Важно

- Убедитесь, что у вас есть подключение к интернету
- Скачивание видео может занять время в зависимости от размера и качества
- Видео сохраняются в папку `downloads` в корне проекта
- Проверяйте лицензии и авторские права перед скачиванием видео

## 🔧 Решение проблем

### Ошибка "ModuleNotFoundError: No module named 'flask'"
Убедитесь, что вы установили зависимости:
```bash
pip install -r requirements.txt
```

### Ошибка "Cannot find yt-dlp"
Попробуйте обновить yt-dlp:
```bash
pip install --upgrade yt-dlp
```

### Видео не скачивается
- Проверьте URL видео
- Убедитесь, что видео доступно в вашем регионе
- Попробуйте другое качество видео
